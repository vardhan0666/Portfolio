Attack-surface reduction platform for authorized targets. Nmap scans feed a risk engine that scores each finding and writes JSON and PDF reports, behind an authorization gate and an audit log.

  • PostgreSQL

SENTINEL-X

A SOC-style platform that takes security telemetry through detection, correlation, risk scoring and incident response, with live updates over WebSockets. Rule-based detection and an Isolation Forest model run side by side.

  • FastAPI
  • React
  • scikit-learn
  • WebSockets
  • PostgreSQL

RAGForge

Upload PDFs, Word files or web pages and ask questions about them. Answers come from Llama 3 on Groq with page-level citations, plus a multi-document compare mode and per-user data isolation.

  • FastAPI
  • React
  • Qdrant
  • Redis
  • Groq
View repository

A 3D WebGL digital twin of space. Zoom from a planet's surface out to a 35,000-particle Milky Way, with Keplerian orbit physics, live NASA data and an AI assistant that turns a research question into hypotheses and a camera move.
